## Why this matters

On 2026-08-03 the maintainer set an explicit product direction: the explorer
must be **visually rich** — interactive charts are first-class content, the
differentiator over the source .xlsx files ("for tables and lists users could
just use the excels"). The repo's doc comments still encode the opposite
convention ("charts are a below-the-fold enhancement, never the support of the
figure"), and stale docs actively mislead: any future contributor — or agent —
reading them will re-derive the revoked constraint and reject interactive
chart work. This plan updates the recorded conventions so code and direction
agree. It changes no behavior.

What is NOT revoked (do not touch these rules):

- Non-negotiable 1: every number carries provenance.
- Non-negotiable 2: direct costs only, never presented as market prices;
  `costoDirecto === 0` renders "No aplica", never $0.
- Key figures also live in server HTML (SEO/no-JS fallback) — charts are
  *additional* first-class content, not a replacement for HTML numbers.
- Performance care: lazy chunks with skeletons remain the loading pattern.
